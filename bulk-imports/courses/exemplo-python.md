## Módulo 2: Variáveis e Tipos de Dados
Descrição do Módulo: Aprenda a armazenar e manipular dados em Python.

### Aula 1: O que são variáveis
Conteúdo da Aula: Variáveis são como caixas que guardam informações.

**Exemplo:**
```python
nome = "João"
idade = 25
altura = 1.75
```

Cada variável tem um nome e um valor.

### Aula 2: Tipos de dados em Python
Conteúdo da Aula: Python tem vários tipos de dados.

**Principais tipos:**
- **String:** textos ("João", "Python")
- **Integer:** números inteiros (1, 42, -5)
- **Float:** números decimais (3.14, 1.75)
- **Boolean:** True ou False

Para ver o tipo, use: `type(variavel)`

### Aula 3: Operações com números
Conteúdo da Aula: Python é uma calculadora poderosa.

**Operadores matemáticos:**
- Soma: `5 + 3` = 8
- Subtração: `10 - 4` = 6
- Multiplicação: `3 * 4` = 12
- Divisão: `10 / 2` = 5.0

Pratique bastante!

## Módulo 3: Controle de Fluxo
Descrição do Módulo: Tome decisões e repita ações no seu código.

### Aula 1: Condicionais - IF e ELSE
Conteúdo da Aula: Faça seu programa tomar decisões.

**Exemplo:**
```python
idade = 18
if idade >= 18:
    print("Maior de idade")
else:
    print("Menor de idade")
```

O código executa apenas uma das opções.

### Aula 2: Loops - FOR
Conteúdo da Aula: Repita ações automaticamente.

**Exemplo:**
```python
for i in range(5):
    print(i)
```

Isso imprime números de 0 a 4.

**Exemplo prático:**
```python
frutas = ["maçã", "banana", "laranja"]
for fruta in frutas:
    print(fruta)
```

### Aula 3: Loops - WHILE
Conteúdo da Aula: Repita enquanto uma condição for verdadeira.

**Exemplo:**
```python
contador = 0
while contador < 5:
    print(contador)
    contador += 1
```

Cuidado para não criar loops infinitos!
