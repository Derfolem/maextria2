🚀 COMO INICIAR (PRIMEIRA VEZ)
═══════════════════════════════════════════════════════════════════

1. Navegue até a pasta:
   cd /home/fredomi/maextria

2. Execute o script de inicialização:
   ./iniciar.sh

   Isso irá:
   - Instalar todas as dependências
   - Criar arquivo .env
   - Inicializar banco de dados
   - Popular com dados de exemplo

3. Edite as configurações (OPCIONAL):
   nano backend/.env
   
   Configure:
   - EMAIL_USER e EMAIL_PASS (para enviar emails)
   - OPENAI_API_KEY (para recursos de IA)
   - JWT_SECRET (troque em produção)

4. Abra 2 terminais:

   TERMINAL 1 (Backend):
   cd /home/fredomi/maextria/backend
   npm run dev
   
   TERMINAL 2 (Frontend):
   cd /home/fredomi/maextria/frontend
   npm run dev

5. Acesse no navegador:
   http://localhost:5173

🔧 PROBLEMAS COMUNS E SOLUÇÕES
═══════════════════════════════════════════════════════════════════

Problema: "Erro ao conectar com o backend"
Solução: Verifique se o backend está rodando na porta 3001

Problema: "Banco de dados vazio"
Solução: Execute: cd backend && node dist/database/seed.js

Problema: "Erro de CORS"
Solução: Verifique o FRONTEND_URL no arquivo backend/.env

Problema: "npm install falha"
Solução: Certifique-se de ter Node.js 18+ instalado

Problema: "Emails não enviam"
Solução: Configure EMAIL_USER e EMAIL_PASS no .env (opcional)
